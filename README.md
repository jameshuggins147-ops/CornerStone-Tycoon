# Cornerstone Tycoon — MVP with App Icon

## Included
- `index.html`: game
- `manifest.webmanifest`: installable web app metadata and icon registration
- `icon-192.png` and `icon-512.png`: PWA icons
- `apple-touch-icon.png`: iOS home-screen icon
- `sw.js`: offline cache

## Run
Open `index.html` in a browser for a quick test. For installable app behavior, upload all files to an HTTPS static host such as GitHub Pages, then use the browser's Add to Home Screen option. Android and iPhone use this PWA version; native store publishing requires extra packaging and store setup.
